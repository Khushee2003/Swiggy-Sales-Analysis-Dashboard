# Insurance Risk & Claim Analysis Dashboard

## 📊 Project Overview

This project presents an interactive Insurance Risk & Claim Analysis Dashboard developed using Microsoft Power BI.

The dashboard provides insights into insurance policies, claim amounts, customer demographics, car usage, coverage zones, and claim trends through interactive visualizations and KPIs.

## 🎯 Objectives

- Analyze total insurance claim amounts.
- Understand policy distribution by car usage.
- Analyze claim amounts by car make and coverage zone.
- Identify trends in claims across different car years.
- Analyze policies by age group.
- Compare claim amounts across education levels.
- Provide interactive data exploration using Power BI filters.

## 📈 Key Insights

- Total Claim Amount: ₹188M
- Total Policies: 38K
- Average Claim Amount: ₹5K
- Total Claim Frequency: 19K
- Female and Male Policy Analysis
- Claim Analysis by Car Make
- Coverage Zone Analysis
- Education-wise Claim Analysis
